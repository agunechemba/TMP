# The Magic of Programming — Now Live

**A storybook that teaches kids ages 5–11 how to talk to computers.**

Most kids think programming is magic reserved for geniuses in dark rooms. It isn't. It's just giving a very fast, very obedient, very clueless robot friend step-by-step instructions — and every child already knows how to do that.

That's the idea behind **The Magic of Programming**, a free interactive storybook adapted from *Beginning Programming For Dummies* by Wallace Wang. Each chapter is rewritten as a short, friendly story with plain-language explanations, code examples in BASIC, C++, and Revolution, and "Think About It" questions at the end.

It covers the full journey — from what a program actually is, through variables, loops, and arrays, all the way to sorting algorithms, debugging, and building web pages with HTML and JavaScript.

### Why it works for young readers

- 📖 Reads like a book, not a manual — pages turn with a click or the arrow keys
- 🎨 Warm paper textures, drop caps, and progress tracking keep kids engaged
- 🧠 Every concept is explained through a story or everyday analogy
- 💻 Real code examples so it isn't just theory

*No signup. No download. Just open the cover and start turning pages.*
